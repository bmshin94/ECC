## 1. ECC란 무엇인가

ECC(Everything Claude Code)는 단순한 코드 저장소가 아니라 **AI 코딩 에이전트를 위한
운영체제(Agent Harness Operating System)** 에 가깝다.

### 1.1 기본 정보

| 항목 | 내용 |
|---|---|
| 원본 저장소 | `affaan-m/ECC` |
| 포크 저장소 | `bmshin94/ECC` |
| 버전 | v2.2.1 |
| npm 패키지 | `ecc-universal`, `ecc-agentshield` |
| 라이선스 | MIT |
| 제작자 | Affaan Mustafa |
| 전체 파일 수 | 약 3,718개 |
| 공식 사이트 | ecc.tools |

### 1.2 폴더별 실측 구성

| 폴더 | 파일 수 | 역할 |
|---|---|---|
| `agents/` | 68 | 위임 전용 전문 서브에이전트 정의 |
| `skills/` | 584 (292 스킬 폴더) | 필요 시점에만 로드되는 작업 매뉴얼 |
| `commands/` | 94 | 슬래시 명령어 진입점 |
| `rules/` | 122 | 22개 언어/스택별 필수 준수 규칙 |
| `hooks/` | 6 | 도구 이벤트 기반 자동화 설정 |
| `scripts/` | 289 | 설치, 동기화, 오케스트레이션 Node.js 유틸 |
| `tests/` | 320 | 테스트 스위트 |
| `docs/` | 1,507 | 13개 언어 문서(한국어 `docs/ko-KR/` 포함) |
| `ecc2/` | - | Rust 기반 세션 데몬 + TUI 대시보드 |
| `src/` | 20 | Python 멀티 LLM 프로바이더 추상화 |

### 1.3 핵심 4요소

1. **Agents (68개)** — 범위가 제한된 전문가 에이전트. 예: `code-reviewer.md`는
   "신뢰도 80% 이상만 보고, 스타일 취향은 제외, 유사 이슈는 통합" 같은
   노이즈 억제 규칙을 내장한다.
2. **Skills (292개)** — 컨텍스트 절약을 위해 필요할 때만 읽히는 워크플로 문서.
3. **Commands (94개)** — `/plan`, `/code-review`, `/build-fix` 등 사용자 진입점.
4. **Hooks** — 저장 시 자동 포맷팅, `console.log` 경고, 푸시 전 커밋 품질 검사,
   세션 시작/종료 시 컨텍스트 저장 등 라이프사이클 자동화.

### 1.4 이 저장소가 주는 이점

- 반복되는 프롬프트 지시를 설정으로 대체한다.
- 보안, 리뷰, 성능 등 분야별 전문 에이전트를 바로 활용할 수 있다.
- 토큰 최적화 가이드를 통해 비용을 크게 줄일 수 있다.
- 22개 언어 규칙(PHP, React 포함)을 선택적으로 도입할 수 있다.
- 한국어 문서가 이미 제공된다.

## 2. 쉬운 설명

ECC는 **AI 직원을 위한 신입사원 교육 매뉴얼 + 사내 규정집 + 자동화 시스템**이다.

| ECC 구성 | 회사 비유 | 예시 |
|---|---|---|
| Rules | 사규, 취업규칙 | "변수는 const 사용", "커버리지 80% 이상" |
| Skills | 업무 매뉴얼 캐비닛 | "Laravel 보안 점검 절차" |
| Agents | 분야별 전문 팀원 | 보안 담당, 코드 리뷰 담당, DB 담당 |
| Commands | 호출 버튼 | `/code-review` 실행 시 리뷰 프로세스 시작 |
| Hooks | 무인 경비 시스템 | 저장 시 자동 포맷팅, 푸시 전 품질 검사 |

### 2.1 도입 전후 비교

**도입 전**

사용자가 "로그인 기능 만들어줘"라고 요청하면, 테스트 없이 임의의 스타일로
코드가 작성되고 보안 검토가 누락될 수 있다.

**도입 후**

1. `/plan "로그인 기능"` — planner 에이전트가 계획을 세우고 승인을 대기한다.
2. 승인 후 `tdd-workflow` 스킬이 테스트 우선 작성을 유도한다.
3. 저장 시점에 훅이 포맷팅과 타입 체크를 수행한다.
4. `/code-review`로 품질과 보안을 점검한다.
5. `git push` 직전 훅이 커밋 품질을 확인한다.

### 2.2 핵심 요약

ECC는 마법이 아니라 **잘 정리된 마크다운 프롬프트 모음집**이다.
따라서 사용자가 직접 열어 읽고 수정할 수 있다.

## 3. 핵심 질문 7선

### 3.1 설치 및 사용법

권장 설치 경로는 가이드형 설치 마법사다.

```bash
npx ecc-universal@2.2.1 setup
```

Claude Code 내부에서 네이티브 플러그인 명령으로도 설치할 수 있다.

```text
/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc
```

주의: **설치 경로를 중첩하지 말 것.** 플러그인 설치 위에 수동 전체 설치를
겹치면 훅이 중복 실행되고 스킬이 중복 등록된다.

`rules/`는 플러그인으로 배포되지 않으므로 필요한 것만 수동 복사한다.

```bash
mkdir -p ~/.claude/rules/ecc
cp -R rules/common ~/.claude/rules/ecc/
cp -R rules/react ~/.claude/rules/ecc/
cp -R rules/php ~/.claude/rules/ecc/
```

주요 사용 진입점은 다음과 같다.

| 목적 | 진입점 |
|---|---|
| 기능 개발 | `/ecc:plan "설명"` 이후 `tdd-workflow` |
| 코드 리뷰 | `/code-review` |
| 빌드 오류 수정 | `/build-fix` |
| 보안 점검 | `/security-scan` |
| 세션 저장/복구 | `/save-session`, `/resume-session` |

요구 사항은 Node.js 18 이상, Claude Code CLI v2.1.0 이상이다.

### 3.2 플러그인인가, 스킬인가, MCP인가

정체성은 **플러그인**이다. 스킬과 커맨드, 훅, 룰을 함께 담아 배포한다.
MCP는 ECC 자체가 서버인 것이 아니라 `mcp-configs/mcp-servers.json`에
권장 서버 설정 카탈로그를 제공하는 형태다. `ecc-memory-vault` 같은 자체 MCP
서버는 기본 비활성 상태의 선택 항목이다.

### 3.3 API 토큰이 필요한가

기본적으로 필요하지 않다. ECC는 텍스트 설정 집합이며 스스로 API를 호출하지 않는다.

| 상황 | 토큰 필요 여부 |
|---|---|
| ECC 설치 및 사용 | 불필요 |
| 구독 기반 Claude Code 사용 | 불필요 |
| API 종량제로 Claude Code 사용 | Claude Code 자체 요구사항으로 필요 |
| GitHub, Jira, Firecrawl 등 MCP 연동 | 선택적으로 필요 |

`.env.example`의 모든 키는 비어 있으며 대부분 선택 항목으로 표기되어 있다.

토큰 최적화 권장 설정은 다음과 같다.

```json
{
  "model": "sonnet",
  "env": {
    "MAX_THINKING_TOKENS": "10000",
    "CLAUDE_AUTOCOMPACT_PCT_OVERRIDE": "50",
    "CLAUDE_CODE_SUBAGENT_MODEL": "haiku"
  }
}
```

### 3.4 인기 요인

1. Claude Code 확산 시점에 설정 공백을 정확히 채웠다.
2. 스킬 292개 등 압도적인 물량을 제공한다.
3. 마크다운 기반이라 읽기 쉽고 선택적 도입이 가능하다.
4. Claude Code, Codex, Cursor, OpenCode 등 다중 하네스를 지원한다.
5. 해커톤 수상 및 실제 서비스 구축 경험이라는 신뢰 근거가 있다.
6. 13개 언어 문서로 글로벌 유입을 확보했다.
7. Discord, 스폰서십, 주간 릴리스로 커뮤니티를 유지한다.

### 3.5 로컬 에이전트 구축에 도움이 되는가

매우 도움이 된다. 특히 다음 자산이 유용하다.

- `agents/` — 노이즈 억제형 프롬프트 설계 패턴
- `ecc2/src/session/` — Rust 세션 데몬, 스토어, 워크트리 관리 구조
- `src/llm/providers/` — Claude, OpenAI, Ollama 등 멀티 프로바이더 추상화
- `scripts/hooks/` — 라이프사이클 훅 53종 구현 레퍼런스
- 프롬프트 인젝션 방어 문구(Prompt Defense Baseline) 삽입 패턴
- `continuous-learning-v2` — 신뢰도 점수 기반 패턴 학습 및 스킬 승격 구조
- `eval-harness`, `agent-eval` — 에이전트 평가 방법론

전체 설치보다 **레퍼런스 문서로 정독**하는 방식이 효율적이다.

### 3.6 수익화 가능성

가능하다. 상세 내용은 4장을 참고한다.

### 3.7 React나 PHP로 만들 수 있는가

ECC 본체를 다른 언어로 재작성하는 것은 실익이 없다. 본질이 마크다운 프롬프트와
Node.js 훅이기 때문이다. 대신 다음 방향이 유효하다.

**React 방향 — ECC 웹 대시보드**

현재 데스크톱 대시보드는 Tkinter 기반(`ecc_dashboard.py`)이다. 이를 React로
재구성하면 스킬 검색과 미리보기, 에이전트 관계 시각화, 훅 실행 로그 모니터링,
설치 프로파일 GUI 빌더, 토큰 비용 대시보드를 제공할 수 있다.
저장소에 `react-patterns`, `react-performance`, `react-testing`,
`dashboard-builder` 스킬이 이미 포함되어 있어 참고 자료가 충분하다.

**PHP(Laravel) 방향 — 팀 설정 관리 서버**

팀원별 스킬과 룰 배포 관리, 설치 프로파일 버저닝, 변경 감사 로그,
사내 스킬 마켓플레이스를 구현할 수 있다. 저장소에 `laravel-patterns`,
`laravel-security`, `laravel-tdd`, `laravel-verification` 스킬과
`rules/php/` 규칙 5종이 포함되어 있다.

**가장 쉬운 방향 — 자체 스킬과 룰 제작**

언어와 무관하게 마크다운만으로 팀 전용 확장팩을 만들 수 있다.

## 4. 수익화 아이디어

### 4.1 한국형 ECC 스킬팩

| 항목 | 내용 |
|---|---|
| 난이도 | 낮음 |
| 초기 비용 | 거의 없음 |
| 예상 수익 | 월 50만 ~ 300만원 |
| 소요 기간 | 2~4주 |

ECC는 미국 중심으로 구성되어 있어 한국 개발 환경 특화 스킬이 부재하다.

- 금융권 컴플라이언스 룰팩(전자금융감독규정, 망분리, 개인정보보호법)
- 국내 결제 연동 스킬(토스페이먼츠, 아임포트, KG이니시스, 카카오페이)
- 국내 인증 및 메시징 연동(네이버/카카오 로그인, 알림톡, 본인인증)
- NCP, 카카오클라우드 배포 패턴
- 공공 SI 프로젝트 산출물 문서 자동화

수익 모델은 기본팩 무료 공개로 인지도를 확보한 뒤, 금융/공공 프리미엄팩 유료화와
기업 커스터마이징 용역을 병행하는 구조가 적합하다.

### 4.2 기업 AI 코딩 도입 컨설팅

| 항목 | 내용 |
|---|---|
| 난이도 | 중간 |
| 초기 비용 | 없음 |
| 예상 수익 | 건당 500만 ~ 3,000만원 |
| 소요 기간 | 즉시 착수 가능 |

단계별 제공 서비스는 진단, 구축, 교육, 운영으로 나눌 수 있다.
구축 단계에서는 사내 코딩 컨벤션을 `rules/`로 변환하고, `/skill-create`로
레거시 코드에서 스킬을 생성하며, 사내 보안 정책을 훅으로 강제한다.
월 유지보수 계약이 안정적인 반복 수익원이 된다.
AgentShield를 활용한 에이전트 설정 보안 감사를 차별화 요소로 제시할 수 있다.

### 4.3 교육 콘텐츠 및 강의

| 항목 | 내용 |
|---|---|
| 난이도 | 낮음 |
| 예상 수익 | 월 100만 ~ 500만원(누적형) |
| 소요 기간 | 1~2개월 |

| 채널 | 상품 | 가격대 |
|---|---|---|
| YouTube | ECC 해설 시리즈 | 광고 및 유입 |
| 온라인 강의 플랫폼 | 실전 강의 | 9.9만 ~ 19.9만원 |
| 전자책 | AI 에이전트 실전 구축 | 약 2.9만원 |
| 뉴스레터 | 주간 AI 코딩 팁 | 무료 후 유료 전환 |
| 오프라인 | 기업 출강 | 일 100만 ~ 200만원 |

커리큘럼은 에이전트 개요, 프롬프트 설계, 훅 기반 품질 게이트, 스킬 제작 실습,
멀티 에이전트 오케스트레이션, 에이전트 보안 순으로 구성한다.

### 4.4 니치 도메인 스킬 마켓플레이스

| 항목 | 내용 |
|---|---|
| 난이도 | 중상 |
| 예상 수익 | 월 30만 ~ 200만원 |
| 소요 기간 | 2~3개월 |

의료, 법률, 게임, 제조 및 IoT, 회계 및 ERP, 자동차 기능안전 등
ECC에 없는 도메인 스킬팩을 제작해 판매한다.
가격대는 팩당 29~99달러 또는 월 구독 형태가 일반적이다.

### 4.5 팀 설정 관리 SaaS

| 항목 | 내용 |
|---|---|
| 난이도 | 높음 |
| 초기 비용 | 개발 3~6개월 |
| 예상 수익 | 성공 시 월 1,000만원 이상 |

원작자가 운영하는 ECC Pro가 좌석당 월 19달러 모델을 사용하고 있으므로
시장성은 검증된 편이다. 한국 시장 차별화 요소는 온프레미스 및 망분리 환경
지원이다. 해외 SaaS가 진입하기 어려운 금융, 공공 영역을 겨냥할 수 있다.

기술 스택은 프론트엔드 React 및 Next.js, 백엔드 Laravel 조합이 적합하며,
저장소에 포함된 관련 스킬을 그대로 참고할 수 있다.

### 4.6 추천 실행 로드맵

1. 1~2개월: 한국형 스킬팩을 오픈소스로 공개해 신뢰를 확보한다.
2. 2~4개월: 콘텐츠와 전자책으로 개인 브랜딩을 강화한다.
3. 3~6개월: 기업 컨설팅을 수주해 현금 흐름과 레퍼런스를 확보한다.
4. 6~12개월: 축적된 데이터를 기반으로 SaaS 제품화를 진행한다.

### 4.7 유의 사항

- MIT 라이선스이므로 파생 배포 시 저작권 표기를 유지해야 한다.
- 원본이 주간 단위로 갱신되므로 파생물의 유지보수 부담을 고려해야 한다.
- 원작자와의 파트너십도 경쟁 대신 선택할 수 있는 전략이다.
